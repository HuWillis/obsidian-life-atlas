# 项目排期与分工设计

用户已确认：项目首页新增排期与分工入口，用表格维护需求拆分任务；手动新增，也可由助手读取需求后录入。新增和编辑使用弹窗。

字段：关联需求、任务名称、负责人、协作人、计划开始/结束日期、预计工时（小时）、状态和备注。名称必填，负责人和日期可空，日期有值时须合法，结束不得早于开始，工时为非负有限数。状态为未开始、进行中、待验证、已完成、阻塞。

支持按需求、负责人、状态筛选、编辑、删除及撤销。只显示所属项目的数据，只关联同项目需求。需求删除后保留排期记录并提示关联失效，不静默丢弃任务。数据使用原有 Markdown 格式，放在项目下的排期与分工目录，最多四层。旧记录与已有编辑方式保持兼容。

方案：选用现有 Store 与 UI 扩展，避免引入外部系统和依赖。用户已选择手动新增（助手可代录），Excel 导入及插件内 AI 拆解暂不实施。弹窗需有取消、错误提示和键盘操作，周期刷新不能丢失草稿；失败不关闭表单。状态与日期不自动变更已有日常安排。

验证：真实临时文件持久化、项目隔离、字段边界、删除撤销；模拟 DOM 验证表格筛选、弹窗编辑保存、失败保留；实机检查安装后的空表与弹窗，不向真实项目填充示例数据。
