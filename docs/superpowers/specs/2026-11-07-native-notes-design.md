# 原生正文编辑

用户选择：标题创建后直接进入 Obsidian 原生编辑器，支持图片、代码块和双链；不采用工作台内展开编辑原型。

范围：学习笔记、业务知识、工作方法、需求文档、方案决策、开发排障、验证交付与实验记录。排期、账务、日程、课程进度、日记回顾等继续使用现有交互。笔记仍保存在原分类与项目下，目录不超过四层。

行为：新建仅要求标题，创建空白 Markdown 正文并在新标签页以编辑模式打开；标题和编辑按钮也直接打开原生编辑器。首页学习入口同样打开正文。收件箱转成知识笔记时，把原始记录放入正文，成功写入后才移除收件箱记录。创建成功但打开失败时显示已保存、允许重试打开，不能重复新建。

兼容：不批量迁移或改写旧笔记。旧文档的字段注释可删除、正文可任意编辑，工作台仍能读取；新文档不生成固定字段或注释。原生文件重命名后列表使用实际文件名。学习摘要从实际正文提取纯文本，不把 HTML 插入首页。非文档记录继续严格校验。

方案：在工作台展开编辑需要另做编辑能力；用户选择原生编辑器，复用 Obsidian API。新增 Store.createDocument({kind,title,context,body})；工作台调用它，普通 Store.save 保留历史调用兼容。原生文档保存不重建固定字段。

交付：相关测试、中文 README、安装到现有私密笔记库，沿用 Git 同步；发布插件中不含笔记数据。原生 API 以已安装依赖为依据。不添加依赖。
